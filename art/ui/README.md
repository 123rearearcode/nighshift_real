Pictures behind close-up windows (0.57.3). Pixel art, shown at exactly 2x.

  600 x 700. The paper is blank on purpose: the game writes the tickets on it. Keep the paper area
  (`CLIPBOARD_PAPER` in scripts/rooms/counter_room.gd) clear if you repaint it.
