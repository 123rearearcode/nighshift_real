## 6. Integration checks before calling it playable

- Test on a fresh session AND a reload using actual current game flow. Record whether a target Godot 4.7.2 run or only a static composition was checked.
- Clipboard and existing ticket actions work with live text. Customers/PCs render separately and occlude correctly. No floating props, clipped heads or text in unusable perspective.
- Grid stays exactly 20 x 10. Demonstrate a mixed-size PC, long card and small part; rotate/place/reject/cancel without losing or cloning stock. Transfer to/from stock room and reload preserves the same UID/layout.
- If hover-look is implemented later: pointer can enter the view without collapse, drag locks it open, click/focus alternative works, Esc cancels held items safely and exit restores the counter. Existing separate close-up remains a fallback.
- No storage frame, column, label or lighting mask covers usable cells. Valid/invalid/selected states remain readable; hidden actual faults stay hidden. Gameplay fields and condition are not inferred from incidental sprite scratches.
- Existing phone/reviews, money/status, pause/settings, doors and end-night remain reachable despite omitted decorative props. Keep no-hub room navigation and night-clock behaviour.
- Preserve existing suites; run Rooms, Morning, Room workshop, Storage, Navigation, Testing bay and lifecycle regressions as appropriate to actual implementation files. Known B55/B56 and open B57 in checker PR #73 are not claimed fixed by art.
