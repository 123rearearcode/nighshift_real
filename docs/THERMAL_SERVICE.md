Cleaning is teal; Thermal service is purple, with stronger selected borders. Labels remain so
color is not the only cue. Pick up the actual syringe or cloth; the old toggle button is removed.
Mount cooler appears below the CPU socket once there is paste, disappears while mounting or after
a graded/locked result, and returns after rework/new paste. A bad-size blob is still mountable;
this does not remove skill or scam choices. The lever is still required to secure and grade.

Click Paste for three choices. Normal thermal paste costs $3. Super-paste costs $6 and lowers
the estimate by 4°C at equal mount quality; toothpaste is free and adds 14°C, remains a scam and
has the existing thicker flow. Super-paste uses normal flow but a subtle blue-purple tint. All
numbers are trial tuning. No brand/lore or extra supplier mechanic is invented.

A deposited or locked layer must be wiped/reset before changing material. The menu explains that
state and disables choices; selecting another ID cannot relabel what's already on the CPU.
The legacy Complete repaste transaction charges once; the night route charges automatically on
a good locked mount as before. Only completed material earns the cooling effect. Super-paste is
honest, never added to job.scams. Main save and physical per-PC snapshots retain its canonical ID.
Both thermal-report paths apply the same signed heat modifier. No incompatible save shape change.

The reel lives in the vacuum bin now. Press RETRACT on the bin to shorten the hose and bring the
vacuum beside it. It stays short until deliberately pulled out, within owned capacity. This does
not empty dust, does not add suction, and works with existing reel interruption/upgrade rules.
The separate spool drawing/click area is gone. Empty bin is still its own action. Raw click input
hands the retract rectangle to its native button so tools/bin-empty logic cannot also consume it.
